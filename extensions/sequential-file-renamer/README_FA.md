# تغییرنام ترتیبی فایل‌ها — افزونه ContactFlow 3.6

برنامهٔ مستقل و بومی Windows Forms برای تغییر نام تعداد زیادی فایل بدون بازکردن دوبارهٔ پنجرهٔ Rename.

## روش سریع

1. با «انتخاب فایل‌ها» یا Drag & Drop فایل‌ها را اضافه کنید.
2. نام فعلی بدون پسوند داخل کادر انتخاب می‌شود.
3. نام جدید را بنویسید و Enter بزنید؛ تغییر ثبت می‌شود و فایل بعدی آماده است.

## امکانات

- انتخاب هم‌زمان فایل یا کل پوشه و مرتب‌سازی طبیعی نام‌ها
- ردکردن و گزارش مسیر خراب/حذف‌شده/بدون دسترسی بدون متوقف‌کردن بقیه فایل‌های انتخاب‌شده (نسخه فایل 3.6.0.3)
- حفظ خودکار پسوند و جلوگیری از بازنویسی فایل موجود
- Enter برای ثبت و بعدی، Ctrl+Enter برای ردکردن و Ctrl+Z برای Undo واقعی
- جابه‌جایی ترتیب صف و حذف از صف بدون حذف فایل
- پیشنهاد نام ترتیبی با `{n}` و `{n:000}` بدون اجرای اجباری گروهی
- گزارش CSV مسیر قبلی، مسیر جدید و وضعیت هر فایل
- تایپ پیوستهٔ فارسی/راست‌به‌چپ بدون انتخاب مجدد متن پس از هر حرف
- تلاش مجدد کوتاه برای فایل‌هایی که Windows لحظه‌ای قفل کرده است
- نمایش خطا در نوار وضعیت بدون پنجره‌های تکراری Continue/Quit و ثبت جزئیات در گزارش CSV
- اجرای کاملاً آفلاین و بدون دسترسی شبکه یا سطح Administrator

فایل نهایی Release با نام `ContactFlow_3.6_Sequential_File_Renamer_Windows_x64.exe` منتشر می‌شود.
