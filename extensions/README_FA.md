# افزونه‌های کاربردی و ضروری ContactFlow 3.6

سه برنامهٔ مستقل کنار هستهٔ اصلی منتشر می‌شوند:

| افزونه | سیستم | کاربرد |
|---|---|---|
| Sequential File Renamer | Windows x64 | تغییر نام ترتیبی چندصد فایل با Enter، Undo و حفظ پسوند |
| Sequential File Renamer | Android 6+ | انتخاب چندفایل/پوشه، تایپ فارسی، Next، Undo، صف و Save As |
| Messenger Contacts | Android 6+ | تفکیک مخاطبین بر اساس اکشن‌های واقعی پیام‌رسان‌ها و خروجی چندفرمتی |

هر سه فایل از صفحهٔ Release نسخهٔ `v3.6.0` قابل دانلودند. سورس کامل در همین پوشه و ماژول‌های Android قرار دارد.

- راهنمای ابزار ویندوز: [`sequential-file-renamer/README_FA.md`](sequential-file-renamer/README_FA.md)
- راهنمای تغییرنام‌دهنده Android: [`../android/sequentialrenamer/README_FA.md`](../android/sequentialrenamer/README_FA.md)
- راهنمای اپ مخاطبین: [`../android/messengercontacts/README_FA.md`](../android/messengercontacts/README_FA.md)
