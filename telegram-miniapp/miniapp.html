Telegram Integration

Mini App به User Session داخلی Telegram دسترسی مستقیم ندارد. برای کار با مخاطبین از مسیرهای خود Telegram استفاده می‌کنیم: بازکردن یک شماره انتخاب‌شده در Telegram، یا ساخت VCF و Import آن در Contacts سیستم و سپس Sync Contacts در Telegram.

حالت User Client

قابلیت‌های MTProto مانند contacts.importContacts و contacts.resolvePhone فقط با User Session واقعی و App credentials خود برنامه قابل استفاده‌اند. این Workspace نتیجه ساختگی تولید نمی‌کند و Session داخلی Telegram را دور نمی‌زند.
