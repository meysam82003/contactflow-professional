افزودن به Telegram Contacts

Mini App رسمی Telegram نمی‌تواند به‌جای حساب شما متدهای contacts.importContacts یا contacts.resolvePhone را اجرا کند. بدون User Session و App credentials، روش رسمیِ بدون جعل این است که VCF را در Contacts گوشی/سیستم Import کنید؛ اگر Sync Contacts در Telegram روشن باشد، Telegram همان دفترچه مخاطبین را Sync می‌کند.

برای جلوگیری از نتیجه‌ی اشتباه، این نسخه شماره‌ای را صرفاً به خاطر نبود نتیجه «قطعاً بدون Telegram» علامت نمی‌زند.

Checker وضعیت Telegram

Checker شبکه‌ای داخل Mini App غیرفعال است، چون API رسمی Phone Lookup فقط برای User Session است و Mini App/Bot چنین مجوزی ندارد. ContactFlow به‌جای نمایش نتیجه ساختگی، فایل آماده‌ی بررسی و VCF می‌سازد.
