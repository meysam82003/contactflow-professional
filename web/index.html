نصب ContactFlow مثل یک اپ واقعی

برای فعال شدن نصب PWA، برنامه باید از HTTPS یا localhost باز شود. باز کردن مستقیم index.html با file:// برای تست هسته مناسب است، اما نصب PWA و Service Worker را فعال نمی‌کند.

PWA Install
▣

Windows / macOS / Linux

  1. لینک HTTPS برنامه را با Chrome یا Edge باز کنید.
  2. در Chrome از منوی سه‌نقطه، Cast, save, and share → Install page as app را بزنید؛ در Edge روی آیکون App available یا Install کلیک کنید.
  3. بعد از نصب، ContactFlow از منوی Apps/Start مثل یک برنامه مستقل اجرا می‌شود.
◆

Android

  1. لینک برنامه را در Chrome باز کنید.
  2. منوی سه‌نقطه → Add to home screen → Install را بزنید.
  3. آیکون ContactFlow روی صفحه اصلی قرار می‌گیرد.
●

iPhone / iPad

  1. سایت را در Safari باز کنید.
  2. Share → Add to Home Screen را انتخاب کنید.
  3. Open as Web App را روشن کنید و Add را بزنید.
↥

انتشار روی اینترنت

  1. کل فایل‌های همین پوشه را روی یک Static Host دارای HTTPS قرار دهید.
  2. فایل شروع index.html است و Build Step لازم نیست.
  3. پس از Deploy، لینک HTTPS را روی هر دستگاه باز و نصب کنید.
