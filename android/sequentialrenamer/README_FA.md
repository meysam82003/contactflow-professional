# تغییرنام ترتیبی فایل‌ها — Android

نسخهٔ بومی Android ابزار Sequential File Renamer در ContactFlow 3.6 است؛ WebView نیست و برای کار عادی به اینترنت، مجوز کلی حافظه یا حساب کاربری نیاز ندارد.

## روش استفاده

1. «انتخاب فایل‌ها» را بزنید و چند فایل را از System File Picker انتخاب کنید؛ یا با «افزودن پوشه» همهٔ فایل‌های همان سطح پوشه را وارد صف کنید.
2. نام بدون پسوند از قبل انتخاب می‌شود. نام فارسی یا لاتین جدید را کامل بنویسید.
3. دکمهٔ «بعدی» کیبورد یا «ثبت و بعدی» را بزنید تا همان فایل تغییرنام داده شود و فایل بعدی آماده شود.

## امکانات

- انتخاب چندفایل با حفظ ترتیب تحویلی Picker و مرتب‌سازی طبیعی فایل‌های پوشه
- سازگاری با Pickerهای سفارشی/OEM، مسیر جایگزین انتخاب فایل، نمایش پیشرفت خواندن صف و گزارش صریح Provider فقط‌خواندنی
- تایپ پیوستهٔ فارسی/راست‌به‌چپ بدون پاک‌شدن حروف قبلی
- حفظ اختیاری پسوند، پاک‌سازی نام ناسازگار و نرمال‌سازی Unicode
- ردکردن، Undo واقعی آخرین تغییر، بالا/پایین‌بردن و حذف از صف بدون حذف فایل
- الگوی `{n}` و `{n:000}` برای ساخت پیشنهاد نام روی باقی صف
- ذخیرهٔ خودکار صف و بازیابی آن پس از بستن برنامه
- گزارش CSV با URI قبلی/جدید، وضعیت و متن خطا از طریق Save As سیستم
- پردازش متادیتا و Rename در Thread پس‌زمینه و جلوگیری از دوبار اجرا با لمس/Enter سریع

## مرز Android

برنامه از Storage Access Framework و `DocumentsContract.renameDocument` استفاده می‌کند. حافظهٔ داخلی، SD Card و هر Document Provider که `FLAG_SUPPORTS_RENAME` بدهد قابل استفاده است. بعضی ارائه‌دهنده‌های ابری یا Pickerهای سفارشی فقط اجازهٔ خواندن می‌دهند؛ در این حالت برنامه فایل را دست‌کاری نمی‌کند و علت را داخل همان ردیف و گزارش نشان می‌دهد. اگر Provider ابری برای کار خودش اینترنت لازم داشته باشد، اتصال توسط همان Provider مدیریت می‌شود؛ خود این APK مجوز `INTERNET` ندارد.
