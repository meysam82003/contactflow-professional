# قابلیت‌ها و مرزهای نسخه ۳.۵

نسخه ۳.۵ تمام قابلیت‌های ۳.۴ را نگه می‌دارد و سه بخش مشترک به PWA، Desktop، Android و Telegram Mini App اضافه می‌کند.

## شهر و استان

- تشخیص آفلاین شهر و استان از نام فایل، آدرس، فیلد شهر/استان، نام یا یادداشت
- پشتیبانی از فارسی، انگلیسی و نگارش‌های رایج فینگلیش بیش از ۱۲۰ شهر ایران
- ذخیره مستقل `city` و `province` و امکان جستجو با هر دو
- نمایش شهر/استان در فهرست مخاطبین و خروجی‌های جدید
- استفاده از کد تلفن ثابت به‌عنوان fallback تشخیص استان

## اپراتور و منبع

- تشخیص اپراتور اولیه از پیش‌شماره موبایل ایران
- حالت منبع خودکار، منبع ثابت برای همه Importهای بعدی یا حفظ منبع فایل
- ذخیره قانون انتخاب‌شده روی همان دستگاه و اعمال یکپارچه در Smart Import
- ذخیره `operator`، `operatorPrefix` و هشدار ترابردپذیری روی مخاطب

پیش‌شماره فقط اپراتور اولیه را نشان می‌دهد. به‌دلیل ترابردپذیری، تشخیص قطعی اپراتور فعلی بدون سرویس استعلام مجاز ممکن نیست.

## کانال‌های ارتباطی

- مرکز مشترک برای Telegram، WhatsApp، Rubika، Bale و Soroush Plus
- قالب پیام با متغیرهای نام، شماره، شهر، استان، اپراتور و منبع
- فیلتر تبلیغاتی فقط برای `optin` و پیام خدماتی برای `optin` یا `existing_chat`
- خروجی CSV صف با وضعیت `pending_manual_confirmation`
- خروجی VCF مخاطبین مجاز برای ذخیره در دفترچه پیام‌رسان/گوشی
- WhatsApp Click-to-Chat و Telegram Share Picker رسمی
- URL Template محلی و قابل تنظیم برای پیام‌رسان‌هایی که لینک عمومی رسمی/پایدار ارائه نمی‌کنند
- fallback کپی متن و بازکردن نسخه وب پیام‌رسان

ContactFlow به Session داخلی اپ‌های نصب‌شده دسترسی نمی‌گیرد، ضداسپم را دور نمی‌زند و ارسال بدون تأیید کاربر انجام نمی‌دهد. Telegram User Session رسمی قبلی همچنان برای قابلیت‌های واقعی حساب به API ID/Hash و QR مستقل نیاز دارد.

## سازگاری

- IndexedDB نسخه ۵ با Indexهای `province` و `operator`
- Backup نسخه ۷ و حفظ سازگاری داده‌های قبلی
- Service Worker و تمام بسته‌های PWA/Desktop/Android/Mini App شامل فایل‌های ۳.۵
- تست واحد برای تشخیص شهر/استان، اپراتور، قانون منبع، رضایت و لینک‌های تحویل
