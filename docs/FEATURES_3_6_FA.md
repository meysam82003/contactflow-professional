# قابلیت‌ها و مرزهای نسخه ۳.۶

## به‌روزرسانی افزونه‌های ضروری

- فاصلهٔ قالب‌های چسبیده مانند `{city}{province}` به‌صورت خودکار اصلاح می‌شود و نام‌های قدیمی مانند `ابرکوهیزد` نیز مهاجرت می‌کنند.
- افزونهٔ native ویندوز برای تغییرنام ترتیبی فایل‌ها با Enter، Undo، حفظ پسوند، کنترل تداخل، Drag & Drop و گزارش CSV اضافه شد.
- افزونهٔ native و آفلاین Android برای تفکیک مخاطبین بر اساس اکشن واقعی پیام‌رسان‌ها و خروجی TXT/CSV/XLSX/VCF اضافه شد.

## Import اتمیک

- دکمه اصلی «تحلیل و ثبت در مخاطبین» کل جریان Parse، Merge، Transaction و راستی‌آزمایی شمارش دیتابیس را اجرا می‌کند.
- حالت «فقط پیش‌نمایش» اختیاری است و نتیجه آن با دکمه جدا ثبت می‌شود.
- Undo هر فایل، Rollback آخرین Merge، گزارش تکراری و تصمیم Smart/Old/New حفظ شده‌اند.
- سیاست منبع ذخیره‌شده روی CSV، TSV، TXT، Excel، JSON، VCF، Telegram Export و Legacy Toolbox اعمال می‌شود.

## نام‌گذاری دقیق

- تغییر نام همه مخاطبین یا تعداد دقیق انتخاب‌شده در یک Transaction.
- قالب‌های `{n}`، `{n:000000}`، `{city}`، `{province}`، `{operator}`، `{source}`، `{phone}`، `{phone:last4}`، `{old}`، `{first}` و `{last}`.
- ترتیب پایدار و جلوگیری از نام تکراری داخل هر Batch.

## Telegram بدون API ID/Hash

- خواندن محلی فایل رسمی Telegram Desktop در قالب `result.json`، HTML یا VCF.
- پیش‌نمایش، جستجو، حذف تکراری، Import به ContactFlow و خروجی VCF/CSV.
- قابل استفاده در Mini App، PWA، Android و Desktop با انتخاب صریح فایل.
- بدون ورود به Session داخلی Telegram و بدون ذخیره رمز یا API Hash.

`Telegram.WebApp` فهرست خصوصی مخاطبین حساب را مستقیم در اختیار Mini App نمی‌گذارد؛ بنابراین انتخاب فایل رسمی، مسیر اصلی و قابل ممیزی نسخه ۳.۶ است.

## هوش شهری

- رتبه‌بندی شهرها و سهم هر شهر از کل داده.
- پوشش استان‌ها، ترکیب اپراتورها، منابع برتر و تمرکز سه شهر اول.
- امتیاز کیفیت بر اساس نام، موقعیت و اپراتور.
- تشخیص و اصلاح نام شهرهای فارسی، English و Finglish و خروجی CSV آمار.

## جعبه‌ابزار V14

- TXT/CSV/TSV/VCF/JSON به مخاطب و VCF/CSV.
- ارجاع XLS/XLSX به Parser کامل Import یکپارچه.
- قالب شماره `+98`، `0098`، `98` یا `09`.
- فایل VCF تکی یا Chunk، Merge چند فایل، حذف تکراری و گزارش جداگانه تکراری‌ها.
- تبدیل Text/Unicode به Hex و برعکس و تصویر به Base64 Data URL.
- اجزای قدیمی لایسنس، FTP و پرداخت عمداً بازگردانی نشده‌اند.

## کانال‌ها و ذخیره فایل

- Telegram، WhatsApp، Rubika، Bale و Soroush Plus در داشبورد و مرکز کانال‌ها قابل مشاهده‌اند.
- خروجی و تحویل تبلیغاتی فقط برای مخاطب دارای رضایت و با تأیید دستی یا API رسمی انجام می‌شود.
- Android از `ACTION_CREATE_DOCUMENT` و مرورگرهای سازگار از File System Access برای Save As استفاده می‌کنند؛ Download fallback باقی مانده است.

## آفلاین و اپ‌های نصب‌شده

- تمام موتورهای Import، نام‌گذاری، Telegram Export، آمار شهری، Legacy Tools، مخاطبین و خروجی بدون شبکه اجرا می‌شوند.
- APK Android شامل Assetهای محلی، IndexedDB، System Picker، دسترسی مجوزمحور دفترچه و OCR محلی است.
- Desktop هسته را داخل فایل اجرایی Embed می‌کند و از Origin محلی استفاده می‌کند؛ PWA و Mini App همان قرارداد داده را دارند.
