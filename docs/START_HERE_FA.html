1) شروع سریع

1
نسخه مناسب را اجرا کنید.
Windows Setup برای نصب عادی؛ Portable برای اجرای بدون نصب.
2
Server مرکزی را تنظیم کنید.
برای Login چنددستگاهی، Sync و Telegram باید URL HTTPS مرکزی داشته باشید.
3
ثبت‌نام و Recovery Code.
Recovery Code را خارج از برنامه و در محل امن نگه دارید.

2) حساب یکسان روی همه دستگاه‌ها

دستگاه اول و دوم باید هر دو به یک apiBase مرکزی وصل باشند. سپس با همان Username و Password وارد می‌شوید و Snapshot/Cloud Files حساب خودتان را دریافت می‌کنید.

Device A → HTTPS ContactFlow Server ← Device B
↓ encrypted snapshots / files ↓

3) Import چندفایلی

چند فایل را هم‌زمان به صف اضافه کنید و برای هرکدام City، Section، Source، Template، Start Number و Phone Column مستقل تعریف کنید. Queue آنها را به‌ترتیب اجرا می‌کند.

CSVTSVTXTXLSX

4) Export چندبخشی و ZIP

مثلاً برای 10,000 مخاطب، Chunk Size را 1,000 بگذارید تا 10 فایل ساخته شود. با گزینه ZIP همه قطعه‌ها در یک بسته قرار می‌گیرند.

contacts_0001.vcf
contacts_0002.vcf
...
contacts_0010.vcf
contacts_all.zip

5) Sync و حل HTTP 404

127.0.0.1 پورت رابط Desktop، Cloud Server نیست.

اگر Login/Register/Telegram همگی 404 می‌دهند، apiBase به UI محلی اشاره می‌کند. باید Server مرکزی HTTPS را قرار دهید.

window.CONTACTFLOW_CONFIG = {
  apiBase: "https://contact.example.com"
};

6) Telegram Mini App

1
با BotFather یک Bot بسازید و Token بگیرید.
2
Bot Token، Admin Numeric ID و Mini App HTTPS URL را در ContactFlow وارد کنید.
3
Menu/Main Mini App را فعال کنید.
4
Mini App باید initData را به Server بفرستد و Server آن را اعتبارسنجی کند.

راهنمای جزئی و عیب‌یابی کامل در فایل TELEGRAM_GUIDE_FA.md قرار دارد.

7) Private Chat از طریق Telegram Business

Bot را به Telegram Business Account متصل کنید. سپس ContactFlow Business Connection و Private Chatهای موجود را Sync می‌کند. ارسال با business_connection_id از طرف حساب Business متصل انجام می‌شود، مشروط به حقوق اتصال و وجود Chat در همان Connection.

Telegram Business Account → Connected Bot → ContactFlow Mini App
→ Existing Private Chats → Selected Message

8) امنیت

Tokenدر Frontend یا فایل عمومی قرار ندهید.
RecoveryRecovery Code را جدا از دستگاه اصلی نگه دارید.
HTTPSبرای حساب و Mini App از HTTPS معتبر استفاده کنید.
